## Integrating information by Kullback-Leibler constraint for text classification

Shu Yin 1,2 · Peican Zhu 2 · Xinyu Wu 3 · Jiajin Huang 4 · Xianghua Li 2 · Zhen Wang 2 · Chao Gao 2,3

Received: 20 October 2022 / Accepted: 11 April 2023 / Published online: 5 May 2023 /C211 The Author(s), under exclusive licence to Springer-Verlag London Ltd., part of Springer Nature 2023

## Abstract

Text classification is an important assignment for various text-related downstream assignments, such as fake news detection, sentiment analysis, and question answering. In recent years, the graph-based method achieves excellent results in text classification tasks. Instead of regarding a text as a sequence structure, this method regards it as a co-occurrence set of words. The task of text classification is then accomplished by aggregating the data from nearby nodes using the graph neural network. However, existing corpus-level graph models are difficult to incorporate the local semantic information and classify new coming texts. To address these issues, we propose a Global-Local Text Classification (GLTC) model, based on the KL constraints to realize inductive learning for text classification. Firstly, a global structural feature extractor and a local semantic feature extractor are designed to capture the structural and semantic information of text comprehensively. Then, the KL divergence is introduced as a regularization term in the loss calculation process, which ensures that the global structural feature extractor can constrain the learning of the local semantic feature extractor to achieve inductive learning. The comprehensive experiments on benchmark datasets present that GLTC outperforms baseline methods in terms of accuracy.

Despite the significance of deep learning methods in text classification, existing research identifies that methods using Graph Neural Networks (GNN) outperform traditional Machine Learning (ML) and deep learning methods for classifying text [22]. Currently, existing methods-based graph can be divided into two categories according to the input structure of texts [23]. Corpus-level methods build a heterogeneous graph for the entire text set, which can effectively extract word co-occurrence information from the graph, thereby extracting global structural information of texts and processing more complex text datasets [24]. Text-level methods build a text-level graph for each text, so these methods can effectively extract semantic information of texts and learn richer word features [25]. However, existing GNN-based models rarely consider both global co-occurrence information and local context information. In addition, existing methods applied for extracting the global graph structure information cannot classify new documents because the global graph structure will be changed when new texts appear in the training process.

To solve these problems, we present a Global-Local Text Classification model (GLTC) based on the idea of Kullback-Leibler (KL) constraint in this paper. First, we design a global structural information extractor. It models the text collection as a heterogeneous graph and then uses the multi-layer GCN model to implement information transfer to learn the low-dimensional text embedding representations with global structural information. Then, a local semantic information extractor is designed. It utilizes a bidirectional Gate Recurrent Unit (GRU) to model documents and learns low-dimensional document representation embeddings that incorporate the local contextual information. Finally, the KL constraint is introduced to realize the inductive learning. Specifically, we use the KL divergence to measure the distribution difference of the output between local and global parts. Then, such a difference is applied as the regularization term of the loss function. This innovation ensures that the local part of the model eventually learns the information obtained by the fusion of two parts. Compared with previous models, our model not only can fully incorporate the global feature of the text set and the local feature of the sentence, but also enables real-time classification for emerging texts. Some experiments are implemented on six benchmark datasets to highlight the performance of our method in terms of accuracy. The main contributions of this paper are as follows.

- We propose a text classification model that focuses on both global structural information and local semantics
- information. Specifically, we use the multi-layer GCN to learn text representations with global structural features and the bidirectional GRU to learn text representations with local semantic features.
- To realize the classification of new texts, we introduce the KL constraint in training phase. Specifically, we use the KL divergence to make the global structure information extractor constrain the local semantic feature extractor, which realizes the inductive learning of model.
- We employ a series of experiments to display the utility of GLTC.

## 2 Related work

Firstly, we present methods for text classification using machine learning in this section. Since graph-based methods, as a class of deep learning methods, can better extract text structure information, we categorize the machine learning methods into three groups (traditional methods, deep learning methods, and graph-based methods) [14]. Then, we introduce related methods of contrastive learning, which is applied to constrain the feature information in our method.

## 2.1 Text classification

## 2.1.1 Traditional methods

The traditional machine learning method has been widely used in the field of text classification in the past ten years [26]. These methods first extract features and then select an appropriate classifier for classification. Logistic Regression (LR) is one of the earliest classification methods [27]. Currently, text classification algorithms based on improved NB are popular [28]. Wang et al. propose a Multinomial Naive Bayes (MNB) tree based on information gain measure, which reduces time consumption while improving classification accuracy [12]. MNB requires the independence assumption of dependent attributes, so Jiang et al. propose a method named SEMNB, which uses the average of all weighted single-dependency polynomial estimates to alleviate the independence assumption of MNB and improve performance [13]. However, since the potential value in the feature space needs to be evaluated by a frequentist, NB is often limited by data scarcity [29].

The core of KNN is to find the category of K points closest to the test data to predict its category. Due to the high computational complexity of traditional KNN, Zhou et al. use a clustering algorithm to process the training dataset and use the weight value to represent the

importance of each training sample. This algorithm reduces time consumption while improving classification accuracy [30]. In addition, when the distribution of data categories is unbalanced, KNN has low prediction accuracy for rare categories. Therefore, a method called NWKNN sets different weights for different categories to improve the classification performance of the imbalanced corpus [31]. However, the performance of KNN and its improved algorithms is related to the design of the distance function, causing such algorithms is dependent on the distribution of data [32].

SVM finds an optimal hyperplane that divides different categories of data in the feature space to classify the text [33]. Joachims et al. propose the Transductive Support Vector Machine (TSVM) for text classification, using a transductive approach to use the test set as an additional source of information to improve classification performance [34]. However, SVM is sensitive to missing data, so it has higher requirements for datasets [35].

Decision tree is a classification method that constructs a tree structure based on attributes to make decisions. Su et al. design an information gain-based decision tree that improves classification accuracy while reducing time complexity and being scalable to datasets with a large number of attributes [36]. Fast Decision Tree (FDT) is a fast text classification method based on DT, which uses the idea of data partition and feature pre-selection to speed up the induction of the decision tree [37]. In addition, Bigi proposes a KL-based method to realize text classification in view of word frequency matching, in which the KL-based information matching mechanism provides a way in the field of text classification [38]. However, with the rapid growth of Internet information, it is labor-consuming and time-costing for these traditional methods to classify a large number of texts [14].

## 2.1.2 Deep learning methods

Convolutional neural networks (CNN) are frequently employed in classifying texts due to their superb local information acquisition ability. Kalchbrenner et al. design a dynamic CNN to solve the issue of long-distance word interaction that cannot be solved by traditional CNN [39]. More specifically, they adopt a dynamic pooling approach for text classification, which effectively captures the longterm dependencies of words. Kim et al. design the TextCNN based on convolution operations to capture the essential information of sentences in different windows sizes in order to better learn the local correlation of sentences [40].

Compared with the CNN-based classification model, the recurrent neural networks (RNN)-based model has a more significant advantage in understanding long semantics because the specified cell of RNN can identify the time series relationship of context. Liu et al. come up with the LSTM-based information-sharing models called TextRNN for text classification with multi-task learning [41]. Compared with the standard LSTM model, the Tree-LSTM model based on the tree structure proposed by Tai et al. has different forget gate in each subunit [42]. And these subunits can learn richer semantic information and text representation embeddings by selectively trading off the information.

With the widespread focus on attention mechanisms and transformers [21], pre-trained language models are used for some text classification methods [43]. The attention mechanism in these model can represent the different language segments weights in the form of a vector. Yang et al. invent a different attention mechanism for sentences and words, which has the ability to provide different attention to sentences and words with different importance in texts [44]. LEAM uses a joint embedding vector of words and labels to better learn the text representation and then further adds the attention mechanism, capturing the dependence of words in texts [45].

The above methods only take text sequences as model inputs. In fact, the sentence or text structure can be better captured if the available graph information is used as an additional input.

## 2.1.3 Graph-based methods

Graph neural network (GNN) can effectively classify the text by training the graph as the input data, which can be applied to node-level, edge-level, and graph-level tasks [22]. More and more researchers use GNN for text classification tasks due to its outstanding structural representation ability. Some studies build a graph structure for corpuses to obtain the global information. TextGCN model is proposed based on GCN to learn the features of words and texts by constructing a global heterogeneous graph based on word co-occurrence [24]. To obtain richer information, Liu et al. propose TensorGCN by constructing multi-graphs for corpuses based on semantics, syntax, and sequences to learn node embeddings based on the intragraph propagation and inter-graph propagation [46]. Aiming at the sparse problem of short text, the HGAT model is designed by building heterogeneous graphs based on texts, topics, and entities to realize complex interaction of information [47]. In order to associate the global information and local semantic information efficiently, Fan et al. use a GraphSEAT containing the bidirectional GRU encoder to obtain the global information from the constructed document-entity heterogeneous graph and the local semantic information from text sequences, respectively [48].

Though these corpus-level models can effectively capture global information from text data, they cannot accomplish inductive learning on new texts. Therefore, some researchers aim to solve such problems by constructing text-level graph structures. TextLevelGNN builds a text-level graph for each text to share global parameters [25]. Then, a message-passing system is proposed for obtaining the information of contexts. The TextING model additionally uses sliding windows to capture word co-occurrence relationships in texts and considers generating a novel graph by creating edges based on such co-occurrence relationships [49]. And a gated GNN is applied to learn text embedding by aggregating the neighbor information. However, these corpus-level models do not consider the structural features of the text sets.

## 2.2 Contrastive learning

Contrastive learning (CL) is widely used in deep learning because it can provide a high-quality sample space for data augmentation. More specifically, CL first adopts the data augmentation techniques to construct pairs of positive samples and pairs of negative samples. Then, it improves the similarity between the embedding of positive samples and the difference between the embedding of negative samples through contrast constraints.

Currently, most methods based on the contrastive learning regard the combined similarity between the maximum positive instances and minimum negative instances as the target training model. Chen et al. propose a simple contrastive learning framework based on the visual representation called SimCLR, which constructs positive samples for images through data enhancement methods such as cropping and grayscale [50]. Then, the cosine similarity between the target and positive samples is maximized, while the cosine similarity between the target and negative samples is minimized. In contrast, SimCSE additionally introduces a multi-layer perceptron (MLP) to calculate the correlation of samples based on SimCLR [51]. Gao et al. explore the necessity of contrastive learning in unsupervised or supervised natural language processing tasks [52]. Their model uses dropout as the way to realize the data augmentation and then uses the other data outside the batch as negative examples of comparative learning. In addition, some studies achieve the contrastive learning by constructing pairs of positive samples and learning only the similarities of positive samples. For example, Fang et al. design a presentation learning method based on an autoencoder called Cert, which implements data augmentation through back-translation and fine-tuning the pretrained language model by predicting whether two augmented sentences are from the same sentence [53]. To solve the over-fitting problems of deep neural network,

Chen et al. propose a dual contrastive learning framework, i.e., DualCL, for text classification [55]. DualCL treats the parameters of the classifier as label-aware-based augmented samples and performs contrastive learning by minimizing the similarity between the input samples and augmented samples.

## 3 Formulation of GLTC

In this section, we propose a text classification model (GLTC) that combines global and local information based on the KL constraint. The model consists of three parts as a whole, i.e., Global Structural Feature Extractor (GSFE), Local Semantic Feature Extractor (LSFE), and comparison and integration part. In the GSFE part, we construct a document-word heterogeneity graph based on the word cooccurrences from corpuses. Then, we input the graph structure into a multi-layer GCN to learn relationships between the various texts. In the LSFE part, we adopt a bidirectional GRU to process a single text sequence to learn the semantic feature of texts. In the training process of comparison and integration part, the output of GSFE is used as a positive sample to constrain the output of LSFE. So the local information model can learn the global structure information at the same time. In the prediction stage of comparison and integration part, only LSFE part is used to predict texts, which not only combines structural information with semantic information but also realizes the inductive learning of new texts prediction. ## Traditional deep learning methods

- TextCNN [40] is based on CNN to classify texts, which can extract key information and local dependencies of sentences. The authors propose several different TextCNN models, and we select the CNN-no-static to compare with our proposed method.
- TextRNN [41] is based on RNN to classify texts. RNN are good at processing sequential data and capturing long-range sentence dependencies.
- FastText [59] is an efficient text vector library for fast text classification tasks created by the Facebook Research.

## Pre-trained language model methods

- Transformer [21] is composed of attention mechanisms and mainly consists of two parts: encoder and decoder. We choose the encoder part and then add an output layer to implement the text classification task.
- BERT [18] is a novel pre-training method based on the encoder part of the transformer with a bidirectional structure. There are a series of BERT models released by Google, and we choose the base BERT and add an output layer as a comparison model.

## Graph neural network methods

- TextGCN [24] is a model based on GCN for classifying texts. It constructs a heterogeneous graph of the corpus from word co-occurrence relationships in each text and then uses the GCN with two hidden layers to learn node representations by message passing.
- TextLevelGNN [25] creates a graph and updates node representations using a graph neural network for each text.
- TextING [49] does not take into account the initial weights of nodes. Firstly, a graph is contrasted for each text in corpuses, and then, the model introduces a message-passing mechanism for information interaction between nodes to learn node and text representations.
- TW-TGNN [60] proposes a two-window graph construction method-based graph neural network model with initial weights to capture word correlations.
- TEGNN [61] is a method that uses topological augmentation to exploit the structural features of corpuses and sentence graphs for text classification.

## 4.1.3 Parameter settings

After a series of preliminary experiments, we choose Glove 5 to initialize word embeddings, and the word dimension is 300. For GLTC, Adam (Adaptive momentum) is chosen as the optimizer, with the learning rate set at 0.005 and the dropout set at 0.5. The regularization factor of the loss function is set to 0.5, and the hidden layer dimension is set to 96. During training, we select 10% of the training set at random to serve for validation. In addition, the training process is terminated when the loss of validation set has not declined during 10 consecutive iterations or as soon as 64 iterations have finished. We conduct each experiment 10 times and present the average results. For the baseline model, we keep the parameter settings consistent with the default settings in the original article or implementation [49].

## 4.2 Results and analysis

We assess the effectiveness of GLTC by comparing it with (1) SOTA text classification models on six public datasets and (2) its variants on three well-performing datasets. ## 4.2.3 Loss function analysis

This section analyzes the drop in loss value during the model training. We compare with two methods (TEGCN and GLTC\_KL), where GLTC\_KL is the GLTC model without KL divergence, and we experiment on two datasets with better performance. The experiment results of the experiment are shown in Fig. 3.

It can be seen that on the Ohsumed and R8 datasets, the training speed of the TextING is slower, and the TEGCN model needs more iterations to converge. Compared with GLTC\_KL, GLTC adds KL divergence as a regular term to the loss function. Therefore, in the early stage of training, the loss value of GLTC model is larger. As the quantity of iterations grows, the GLTC model converges faster than the GLTC\_KL model, usually within 50 iterations. The above results show that the model that integrates global structural information and local semantic information is faster to train. In addition, including a KL regularization term in the loss function not only allows the model to predict new texts but also accelerates the model's convergence rate.

## 4.2.4 Effects of the number of GCN layers

This section studies the effect of the number of GCN layers on the classification accuracy of the model. We conduct experiments on GLTC with various numbers of GCN layers using three effective datasets (MR, Ohsumed, and R8). According to the experiment results shown in Fig. 4, the classification accuracy is significantly impacted by the number of GCN layers. The model performs best on these datasets when there are two GCN layers. The reason is that when the model uses a two-layer GCN, the nodes in the graph can obtain second-order neighborhood information. Specifically, text nodes can aggregate not only the information of word nodes directly connected but also the information of text nodes indirectly connected. When there is only one GCN layer, GLTC has poor classification performance on these datasets. The explanation for this is when the model uses a single-layer GCN, only word nodes that are directly linked to text nodes can access information from them, and it is difficult to obtain high-order neighborhood text node information. Furthermore, as the number of GCN layers increases in model, the performance of the model does not improve significantly while consuming a lot of memory. Therefore, choosing an appropriate number

of GCN layers can efficiently learn text representations and improve classification accuracy.

## 4.2.5 Dataset analysis

In this part, we select four typical datasets SST1, SST2, Ohsumed, and R8 for statistical analysis. Among them, SST1 and SST2 belong to the social media field data, which have the characteristics of short text and sparse data. Ohsumed and R8 are datasets in the medical field and the news field, respectively, with long text and features belonging to special fields. The statistical outcomes are displayed in Fig. 5.

The results of the experiment display that SST1 and SST2 have similar data distribution characteristics. The number of documents indirectly connected by words in these datasets is evenly distributed and has a large span. It shows that after social media text is converted into a graph structure, the connection between text nodes is relatively sparse, and there are independent document nodes. Therefore, graph training with GCN models is difficult to provide additional useful information for these isolated nodes. At the same time, due to the sparsity of the graph structure, the information that those indirectly connected text nodes can obtain is also limited. The distributions of the Ohsumed and R8 datasets are quite different from those of SST1 and SST2. We can see from Fig. 5 that the amount of indirectly connected text is relatively concentrated. Most texts can be indirectly connected with other texts, and there are few isolated document nodes in Ohsumed and R8. The minimum number of documents indirectly connected is also close to 1000 in Ohsumed, indicating that after the text in this special field is converted into a graph structure, the connection between text nodes is tight, and there is no isolated text node. Therefore, GCN models can learn the global structural information well for such corpora with closely related texts to learn more accurate text representations, which improves classification performance.

## 5 Conclusion

We propose a KL constraint-based GLTC model for text classification by KL divergence that fuses global structural features and local semantic features in this paper. Firstly, a global structural feature extractor is designed to transform text sets into a heterogeneous graph model, and multi-layer GCN network models are utilized to learn document embedding representations. Then, a local semantic feature extractor is designed to model a single text sequence with a bidirectional gated recurrent unit model. Finally, an improved loss function strategy is designed based on KL constraints for model training. The final text representation learned by the local semantic feature extractor contains both global structural information and local semantic information. And in the prediction stage, inductive learning is achieved by using a local semantic feature extractor to make classification predictions for new texts. Comprehensive experimental on multiple benchmark datasets demonstrates that the GLTC model can reach better performance. However, the GLTC model is sensitive to the parameters of the regularization term. Hence, our future work will concentrate on the model's robustness to explore advanced methods which can better fuse the global structural information and local semantic information.

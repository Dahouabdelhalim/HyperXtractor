Shu Yin¹,² · Peican Zhu² · Xinyu Wu³ · Jiajin Huang⁴ · Xianghua Li² · Zhen Wang² · Chao Gao²,³

## Abstract
Text classification is an important assignment for various text-related downstream assignments, such as fake news detection, sentiment analysis, and question answering. In recent years, the graph-based method achieves excellent results in text classification tasks. Instead of regarding a text as a sequence structure, this method regards it as a co-occurrence set of words. The task of text classification is then accomplished by aggregating the data from nearby nodes using the graph neural network. However, existing corpus-level graph models are difficult to incorporate the local semantic information and classify new coming texts. To address these issues, we propose a Global–Local Text Classification (GLTC) model, based on the KL constraints to realize inductive learning for text classification. Firstly, a global structural feature extractor and a local semantic feature extractor are designed to capture the structural and semantic information of text comprehensively. Then, the KL divergence is introduced as a regularization term in the loss calculation process, which ensures that the global structural feature extractor can constrain the learning of the local semantic feature extractor to achieve inductive learning. The comprehensive experiments on benchmark datasets present that GLTC outperforms baseline methods in terms of accuracy.

**Keywords** Text classification · Graph neural network · Kullback–Leibler divergence · Constraint

## 1 Introduction
As a basic assignment, text classification is able to greatly improve the efficiency of text processing and text mining by dividing the text into predefined categories according to a specific classification standard [1]. It also provides essential methods for other NLP tasks such as text sentiment analysis [2], spam filtering [3, 4], and topic detection in social media [5]. Traditional text classification method is mainly to manually design the feature extractor and then select the appropriate classifier for classification [6, 7]. Commonly used classifiers include Decision Tree (DT) [8], Support Vector Machine (SVM) [9], K-nearest Neighbor (KNN) [10], Multinomial Naive Bayes (MNB) [11, 12], and its improved models [13]. However, it is labor-consuming and time-costing to extract the features manually with the rapid growth of Internet information [14]. Therefore, it is of great significance to use machine automation to extract features and classify text.
Since Deep Learning (DL) can effectively learn feature representation, researchers begin to apply deep learning models to text classification tasks [15]. The method that uses deep learning models for text classification includes two steps: vectorization and model learning. More specifically, vectorization is mainly to convert text into a low-dimensional vector representation. Commonly used vectorization methods include Word2Vec [16], GloVe [17], and BERT [18]. Then, the model learns features from the vector representation of the text to classify text automatically. Currently, the commonly used deep learning models

Despite the significance of deep learning methods in text classification, existing research identifies that methods using Graph Neural Networks (GNN) outperform traditional Machine Learning (ML) and deep learning methods for classifying text [22]. Currently, existing methods-based graph can be divided into two categories according to the input structure of texts [23]. Corpus-level methods build a heterogeneous graph for the entire text set, which can effectively extract word co-occurrence information from the graph, thereby extracting global structural information of texts and processing more complex text datasets [24]. Text-level methods build a text-level graph for each text, so these methods can effectively extract semantic information of texts and learn richer word features [25]. However, existing GNN-based models rarely consider both global co-occurrence information and local context information. In addition, existing methods applied for extracting the global graph structure information cannot classify new documents because the global graph structure will be changed when new texts appear in the training process.

To solve these problems, we present a Global–Local Text Classification model (GLTC) based on the idea of Kullback–Leibler (KL) constraint in this paper. First, we design a global structural information extractor. It models the text collection as a heterogeneous graph and then uses the multi-layer GCN model to implement information transfer to learn the low-dimensional text embedding representations with global structural information. Then, a local semantic information extractor is designed. It utilizes a bidirectional Gate Recurrent Unit (GRU) to model documents and learns low-dimensional document representation embeddings that incorporate the local contextual information. Finally, the KL constraint is introduced to realize the inductive learning. Specifically, we use the KL divergence to measure the distribution difference of the output between local and global parts. Then, such a difference is applied as the regularization term of the loss function. This innovation ensures that the local part of the model eventually learns the information obtained by the fusion of two parts. Compared with previous models, our model not only can fully incorporate the global feature of the text set and the local feature of the sentence, but also enables real-time classification for emerging texts. Some experiments are implemented on six benchmark datasets to highlight the performance of our method in terms of accuracy. The main contributions of this paper are as follows.

*   We propose a text classification model that focuses on both global structural information and local semantics information. Specifically, we use the multi-layer GCN to learn text representations with global structural features and the bidirectional GRU to learn text representations with local semantic features.
*   To realize the classification of new texts, we introduce the KL constraint in training phase. Specifically, we use the KL divergence to make the global structure information extractor constrain the local semantic feature extractor, which realizes the inductive learning of model.
*   We employ a series of experiments to display the utility of GLTC.

## 3 Formulation of GLTC

In this section, we propose a text classification model (GLTC) that combines global and local information based on the KL constraint. The model consists of three parts as a whole, i.e., Global Structural Feature Extractor (GSFE), Local Semantic Feature Extractor (LSFE), and comparison and integration part. In the GSFE part, we construct a document-word heterogeneity graph based on the word co-occurrences from corpuses. Then, we input the graph structure into a multi-layer GCN to learn relationships between the various texts. In the LSFE part, we adopt a bidirectional GRU to process a single text sequence to learn the semantic feature of texts. In the training process of comparison and integration part, the output of GSFE is used as a positive sample to constrain the output of LSFE. So the local information model can learn the global structure information at the same time. In the prediction stage of comparison and integration part, only LSFE part is used to predict texts, which not only combines structural information with semantic information but also realizes the inductive learning of new texts prediction. Figure 1 shows the general structure of proposed model GLTC.

### 3.1 Global structural feature extractor

In the global structural feature extraction part, we convert a text into a heterogeneous graph and then use the GCN model to update the node representation. Based on word-text connections, we model each text as a corpus-level heterogeneous graph $G = (V, E)$, where $V = \{v_w, v_d\}$ is the nodes set in the graph, $v_w$ and $v_d$ represent the word nodes set and text nodes set in $G$, respectively, and $E$ is the graph edges set that connect word and text nodes. When a text contains a certain word, there is an edge between the text and the word, and the weight of the edge is determined by TF-IDF [56]. TF-IDF believes that the significance of a word increases with the frequency of the word and decreases with the frequency of other words. In other words, if a word frequently appears in a certain text and less frequently appears in other texts, the word can well represent the characteristics of the text. TF-IDF is

Then, the heterogeneous graph $G$ is input into the multi-layer GCN model. Since a single-layer GCN can only learn information from direct neighbor nodes, and there is no direct connection between text and text in the graph, we stack multiple GCN layers to learn high-order neighborhood information. For initial node features, the initial embedding of word nodes is represented by the Glove vector, and the initial embedding of text nodes is the average of all word embedding vectors in the text. We denote the feature matrix of all nodes as $X \in R^{N \times d}$, where $N$ represents the total number of nodes included in the graph, and $d$ represents the node embedding dimension. The multi-layer GCN model takes $A$, $D$, and $X$ as inputs, and then, the model updates the representation of all nodes. A GCN sub-layer and a graph attention layer make up each GCN layer. $$L^{(j+1)} = \sigma(\widetilde{A}H^{(j)}W^{(j)})$$

(2)

where $\sigma$ represents the activation function, $\widetilde{A} = D^{-\frac{1}{2}}AD^{-\frac{1}{2}}$ represents the normalized symmetric adjacency matrix, $H^{(j)}$ represents the input of the $j^{th}$ layer GCN model, $W^{(j)}$ represents the current GCN layer’s weight matrix, $L^{(j+1)}$ represents the output of the $j^{th}$ layer GCN model.

GCN learns the embedding texts representation in a graph using the weighted aggregation of the representation of the text node itself and the representation of the word nodes connected to the text node. Since different words have different importance to texts, we introduce a graph attention layer to learn appropriate neighbor node weights and use a self-attention mechanism to calculate neighbor node weights $a_{vu}$. ### 3.2 Local semantic feature extractor

To learn richer contextual information, we employ a bidirectional GRU model to extract local semantic features for a single text object. GRU adopts a gating mechanism to transmit sequence state information, which is made up of two components: reset gate and update gate. The specific update process is denoted as Eq. (5).

$z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z)$
$r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r)$
$h_t = z_t \odot h_{t-1} + (1 - z_t) \odot \phi(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)$ (5)

where $\sigma$ and $\phi$ are the activation functions, $x_t$ represents the input embedding, $h_t$ and $h_{t-1}$ are the hidden layer state of the model at time $t$ and the previous moment, $W_z$, $W_r$ and $W_h$ are the weight matrices, $b_z$, $b_r$ and $b_h$ are bias.

The one-way GRU model can only process one-way sequence, which may cause the model to lose some important information. Therefore, we adopt a bidirectional GRU model, which retains important information in the context of the predicted word, and then learns the embedding representation of the text based on this information. We input the text sequence $d = \{w_1, w_2, \ldots, w_n\}$ into a bidirectional GRU model, which embeds contextual information into word vectors by combining information from both directions. The forward GRU processes the text sequence from $w_1$ to $w_n$, and the resulting hidden layer state $\vec{h}_n$ is the text vector representation. The backward GRU processes the text sequence from $w_n$ to $w_1$, and the resulting hidden state $\hat{h}_1$ is the text vector representation.

Finally, the two hidden layer states are concatenated into a text representation containing local semantic features

$\text{local}(v) = \begin{bmatrix} \vec{h}_n, & \hat{h}_1 \end{bmatrix}.$

### 3.3 Comparison and integration

#### 3.3.1 Training phase

To fuse global structural information and local semantic information, we employ an attention mechanism to aggregate $global(v)$ and $\text{local}(v)$. The process is formulated as Eq. (6).

$$\begin{cases}
o_g = W_g \cdot global(v) \\
o_l = W_l \cdot \text{local}(v) \\
u_g = \text{tanh}\left(W_1 o_g + b_1\right) \\
u_l = \text{tanh}\left(W_2 o_l + b_2\right) \\
a_g = \frac{\exp(v^T u_g)}{\exp(v^T u_g) + \exp(v^T u_l)} \\
a_l = \frac{\exp(v^T u_l)}{\exp(v^T u_g) + \exp(v^T u_l)} \\
z = \sum a_l o_l + a_g o_g
\end{cases}$$ (6)

where $o_g$ and $o_l$ are the linearly transformed global information document representation and local information document representation, $a_g$ and $a_l$ are the global information weight and local information weight value learned by the attention mechanism, $W_g$, $W_l$, $W_1$ and $W_2$ are trainable weight matrices, $b_1$ and $b_2$ are bias terms, and $z$ is the aggregated global structural information and local semantics information.

Then, the Softmax function is employed to calculate the predicted label and the cross-entropy loss function relies on the true labels to calculate the corresponding predicted label loss. The calculation process is:

$P' = \text{softmax}(Wz + b)$
$Loss_1 = -\sum_{i \in D_{\text{train}}} y_i \cdot \log P'_i$ (7)

where $Loss_1$ represents the original cross-entropy loss function, $D_{\text{train}}$ is the set of texts for training, $W$ represents the trainable weight matrix, $b$ represents the bias term, $P'$ represents the probability distribution of the category, and $y$ is the true label.

The above process of fusing the representations of global and local for classification prediction can be expressed by the probability formula:

$$p(c \mid d) = \mathbb{E}_G \sum_{z', z''} p(c \mid z', z'') \cdot p(z' \mid d) \cdot p(z'' \mid G) \quad (8)$$

where $\mathbb{E}_G$ denotes the expectation of randomly sampling a heterogeneous graph $G$, $p(z' \mid d)$ denotes the representation $z'$ of a text $d$ randomly sampled by the LSFE, $p(z'' \mid G)$ denotes the text representation $z''$ obtained by randomly sampling heterogeneous graphs $G$ with GSFE, $p(c \mid z', z'')$ denotes the label probability distribution learned by the fusion of the two sampled text representations using the attention mechanism, and $p(c \mid d)$ denotes the final classification label of text $d$.

However, the GSFE part puts all training and test set nodes into the graph during the construction phase. When making classification predictions, this part can only classify the test samples contained in the graph and cannot classify new samples. To address this issue, we consider injecting the global structural information in GSFE into LSFE during training and directly using LSFE for prediction in the final prediction stage. As shown in Fig. 2, we introduce KL constraint in the training phase, regard GSFE as a data enhancer for positive samples, and compare the text representation learned by GSFE with the text representation learned by LSFE.

KL divergence can be the quantification of the disparity between probability distributions, which is used to measure the degree of difference between the approximate distribution of the data and the original distribution of the data. The larger the difference between the two probability distributions, the larger the KL divergence value calculated from the two probability distributions. Therefore, for the loss function, we introduce the KL divergence loss as a regularization term to jointly train the model. By minimizing the KL divergence, the document representation learned by the LSFE contains the global structural information of the GSFE. First, we transform the global document representation $\text{global}(v)$ and the local document representation $\text{local}(v)$ through a layer of nonlinear transformation to obtain two probability distribution representations $p_\text{global}$ and $p_\text{local}$, the process can be expressed as:

$$p_\text{global} = \text{softmax}\left(W_\text{global} \cdot \text{global}(v) + b_\text{global}\right)$$
$$p_\text{local} = \text{softmax}\left(W_\text{local} \cdot \text{local}(v) + b_\text{local}\right) \quad (9)$$

Then, we use $p_\text{global}$ to constrain $p_\text{local}$ so that the global representation probability distribution is approximately the same as the local representation probability distribution. $D_\text{KL}\left(p_\text{local} \| p_\text{global}\right)$ is the one-way KL divergence value computed with $p_\text{global}$ constrained by $p_\text{local}$, added to the original cross-entropy loss function as the regularization term. Therefore, the final loss function is Eq. (10):

$$\text{Loss}_{\text{final}} = \text{Loss}_1 + \alpha \cdot D_\text{KL}\left(p_\text{local} \| p_\text{global}\right) \quad (10)$$

where $\text{Loss}_{\text{final}}$ represents the final loss, $D_\text{KL}$ represents the regularization term, and $\alpha$ is the parameter of the regularization term. In summary, during the training process, the KL divergence is used as the regularization term of the loss function and the GSFE part is used to constrain the LSFE part. So the final LSFE part of the model also contains global structure information.

### 3.3.2 Testing phase

In the above training phase, we use the text representation learned by GSFE to constrain the text representation learned by LSFE. The distribution of text representation learned by GSFE is approximately equal to the text representation learned by LSFE. Therefore, the training process after adding KL constraints can be expressed in Eq. (11):

$$\begin{cases} p(c \mid d) = \mathbb{E}_G \sum_{z', z''} p(c \mid z', z'')p(z' \mid d)p(z'' \mid G) \\ p(z' \mid d) = p(z'' \mid G) \quad \text{KL constraints} \end{cases} \tag{11}$$

After introducing the KL constraint, the text representation $p(z' \mid d)$ learned based on LSFE is equal to the text representation $p(z'' \mid G)$ learned based on GSFE. Therefore, in the testing phase, Eq. (11) is combined, and the following process can be obtained as:

$$\begin{aligned}
p(c \mid d) &\overset{\text{step 1}}{=} \mathbb{E}_G \sum_{z', z''} p(c \mid z', z'')p(z' \mid d)p(z'' \mid d) \\
&\overset{\text{step 2}}{\approx} \sum_{z', z''} p(c \mid z', z'')p(z' \mid d)p(z'' \mid d) \\
&\overset{\text{step 3}}{\approx} \sum_z p(c \mid z)p(z \mid d)
\end{aligned} \tag{12}$$

The following explains this derivation step by step:
* Step 1 is obtained by combining Eq. (11).
* Step 2 is because the learned text representation after merging is no longer affected by the GSFE. That is, it is no longer affected by the heterogeneous graph, so $\mathbb{E}_G$ is eliminated.
* Step 3 is to sample two text representation samples from the trained LSFE randomly. Without considering the impact of dropout, we can consider $p(z' \mid d) = p(z'' \mid d)$. The final text expression $z$ is composed of $z'$ and $z''$.

Therefore, in the testing phase, the text representation learned by LSFE can be directly used for classification.

### Traditional deep learning methods

*   **TextCNN** [40] is based on CNN to classify texts, which can extract key information and local dependencies of sentences. The authors propose several different TextCNN models, and we select the CNN-no-static to compare with our proposed method.
*   **TextRNN** [41] is based on RNN to classify texts. RNN are good at processing sequential data and capturing long-range sentence dependencies.
*   **FastText** [59] is an efficient text vector library for fast text classification tasks created by the Facebook Research.

### Pre-trained language model methods

*   **Transformer** [21] is composed of attention mechanisms and mainly consists of two parts: encoder and decoder. We choose the encoder part and then add an output layer to implement the text classification task.
*   **BERT** [18] is a novel pre-training method based on the encoder part of the transformer with a bidirectional structure. There are a series of BERT models released by Google, and we choose the base BERT and add an output layer as a comparison model.

### Graph neural network methods

*   **TextGCN** [24] is a model based on GCN for classifying texts. It constructs a heterogeneous graph of the corpus from word co-occurrence relationships in each text and then uses the GCN with two hidden layers to learn node representations by message passing.
*   **TextLevelGNN** [25] creates a graph and updates node representations using a graph neural network for each text.
*   **TextING** [49] does not take into account the initial weights of nodes. Firstly, a graph is contrasted for each text in corpuses, and then, the model introduces a message-passing mechanism for information interaction between nodes to learn node and text representations.
*   **TW-TGNN** [60] proposes a two-window graph construction method-based graph neural network model with initial weights to capture word correlations.
*   **TEGNN** [61] is a method that uses topological augmentation to exploit the structural features of corpuses and sentence graphs for text classification.

#### 4.1.3 Parameter settings

After a series of preliminary experiments, we choose Glove<sup>5</sup> to initialize word embeddings, and the word dimension is 300. For GLTC, Adam (Adaptive momentum) is chosen as the optimizer, with the learning rate set at 0.005 and the dropout set at 0.5. The regularization factor of the loss function is set to 0.5, and the hidden layer dimension is set to 96. During training, we select 10% of the training set at random to serve for validation. In addition, the training process is terminated when the loss of validation set has not declined during 10 consecutive iterations or as soon as 64 iterations have finished. We conduct each experiment 10 times and present the average results. For the baseline model, we keep the parameter settings consistent with the default settings in the original article or implementation [49].

### 4.2.2 Ablation experiments

We perform ablation experiments in this part to investigate the significance of global and local modules. We remove the global feature extractor as GLTC_G and local feature extractor as GLTC_L, respectively, and conduct experiments on three well-performing datasets (MR, Ohsumed, and R8). The classification accuracy of the test set on three datasets is shown in Table 4.

Compared with GLTC_G, GLTC demonstrates a considerable improvement in classification accuracy on three datasets, which is 2.61% higher on the MR dataset, 22.55% higher on the Ohsumed dataset, and 1.86% higher on the R8 dataset. GLTC_G only relies on the local sequence information to model the text, so it cannot learn the text representation that incorporates global structural information. Especially, the improvement of GLTC is very significant on the Ohsumed dataset, which further demonstrates the importance of global structural information in the text classification of specialized fields. Compared with GLTC_L, the classification accuracy of GLTC has a significant improvement on the three datasets, which is 3.52%, 3.46% and 1.1% higher on the MR, Ohsumed and R8 datasets, respectively. GLTC_L only relies on the heterogeneous graph constructed by word co-occurrence to model text features, so it cannot learn fine-grained text features. More importantly, GLTC_L cannot classify new texts since the heterogeneous graph structure changes when new documents appear.

4.2.3 Loss function analysis

This section analyzes the drop in loss value during the model training. We compare with two methods (TEGCN and GLTC_KL), where GLTC_KL is the GLTC model without KL divergence, and we experiment on two datasets with better performance. The experiment results of the experiment are shown in Fig. 3.

It can be seen that on the Ohsumed and R8 datasets, the training speed of the TextING is slower, and the TEGCN model needs more iterations to converge. Compared with GLTC_KL, GLTC adds KL divergence as a regular term to the loss function. Therefore, in the early stage of training, the loss value of GLTC model is larger. As the quantity of iterations grows, the GLTC model converges faster than the GLTC_KL model, usually within 50 iterations. The above results show that the model that integrates global structural information and local semantic information is faster to train. In addition, including a KL regularization term in the loss function not only allows the model to predict new texts but also accelerates the model’s convergence rate.

### 4.2.5 Dataset analysis

In this part, we select four typical datasets SST1, SST2, Ohsumed, and R8 for statistical analysis. Among them, SST1 and SST2 belong to the social media field data, which have the characteristics of short text and sparse data. Ohsumed and R8 are datasets in the medical field and the news field, respectively, with long text and features belonging to special fields. The statistical outcomes are displayed in Fig. 5.

The results of the experiment display that SST1 and SST2 have similar data distribution characteristics. The number of documents indirectly connected by words in these datasets is evenly distributed and has a large span. It shows that after social media text is converted into a graph structure, the connection between text nodes is relatively sparse, and there are independent document nodes. Therefore, graph training with GCN models is difficult to provide additional useful information for these isolated nodes. At the same time, due to the sparsity of the graph structure, the information that those indirectly connected text nodes can obtain is also limited. The distributions of the Ohsumed and R8 datasets are quite different from those of SST1 and SST2. We can see from Fig. 5 that the amount of indirectly connected text is relatively concentrated. Most texts can be indirectly connected with other texts, and there are few isolated document nodes in Ohsumed and R8. The minimum number of documents indirectly connected is also close to 1000 in Ohsumed, indicating that after the text in this special field is converted into a graph structure, the connection between text nodes is tight, and there is no isolated text node. Therefore, GCN models can learn the global structural information well for such corpora with closely related texts to learn more accurate text representations, which improves classification performance.
